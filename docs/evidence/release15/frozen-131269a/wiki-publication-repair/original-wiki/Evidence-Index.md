# Export and evidence index

These pages derive from the supported QBrain GitHub export. Publication translates repository-relative links to wiki pages or retained evidence; canonical ZIP bytes remain unchanged. No application repository commit or hosted game release is represented.

## Source snapshot boundary

The implementation is a local dirty working tree identified by its complete source-hash manifest. Its uncommitted application files are not published by this wiki update. Non-exported source references remain provenance paths; their unavailable public targets are listed in the publication receipt. Historical reviews apply only to their recorded snapshots.

The evidence archive includes rejected/superseded reports. Fixture UI, actual SQL, real transport and device/provider evidence are separately scoped. Contest readiness still has explicit open dependencies; eligibility is entrant-attested.
