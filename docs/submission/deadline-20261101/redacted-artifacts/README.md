## Transformations and limits

Explicit markers replace credential fields and known or conservatively classified token-like values, personal contacts, host identifiers, home-directory locations, network addresses, private prompts, profile/bootstrap/tool payloads and internal model reasoning. No raw credential values or private guidance are included in the redaction ledger. A conservative literal match is not proof that the literal was a working credential.

JSONL event order and record counts are preserved. JSON values are reserialized; YAML histories and plain-text transport files are represented as JSON. Original and derivative hashes identify different bytes. Empty originals remain represented. Query-parameter records are labeled as inputs and do not establish a successful canonical readback. Whole sensitive fields or tool outputs may be replaced, so these derivatives do not reproduce every original word.

The original complete structured verdicts and failed/unknown findings remain in the adjacent evidence package. This publication adds access to transformed source streams and histories. It does not establish a new accepted review, hosted deployment, contest submission or billing invoice. The scope is the exact referenced artifacts and their companions; unrelated native chat rollouts and runtime configurations remain private.

The first private staging copy failed YAML-list privacy controls; a later scan found escaped-path, hardware-address and additional-bootstrap matches. Those copies were retained privately and never uploaded. The published copy passed the final independent scan and the corrected fixture controls. Static checks and known-value matching cannot prove the absence of every possible private identifier; the validation file records this limit.
