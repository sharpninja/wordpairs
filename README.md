# Wordpairs

Wordpairs is a real-time word-association game. Its approved requirements and rendered diagrams are in [`docs/word_association_game_requirements.md`](docs/word_association_game_requirements.md).

## Project status

This repository starts with planning documentation and diagrams. Application code has not started. Per the project's Byrd Development Process v4, implementation begins with tests for the next small behavior, coverage of every applicable acceptance criterion, and validation of those tests against mocks before implementation code is written.

## Deployment target

The intended deployment target is Vercel, with the GitHub repository `sharpninja/wordpairs` as the source. Vercel configuration and application implementation remain pending.
